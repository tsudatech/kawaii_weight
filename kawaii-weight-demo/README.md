# たいかん！（デモ v0.5・旧名 かわいい体重管理）

キャラクターが体重の変化にリアクションする、iOS アプリの UI デモです。
HTML / CSS / JavaScript だけで動きます。

## 開き方

`index.html` をブラウザ（Safari / Chrome）で開いてください。サーバーは不要です。
データはブラウザの localStorage に保存されます。最初は約3か月分のサンプルデータが入っています。
「せってい › データ › サンプルデータに戻す」で初期状態に戻せます。

## フォルダ構成

```
index.html                 画面の構造
css/style.css              見た目（色・フォントは :root の変数にまとめています）
js/app.js                  動き・表情の判定・サンプルデータ
assets/characters/         キャラ画像（ハムスター）
  lg_表情.png              大サイズ 720×720（ホーム・おへや・日の詳細・シェアカードなど）
  sm_表情.png              小サイズ 240×240、頭と肩まで（りれき・カレンダー・きぶん選択・ずかん・ウィジェット）
  original/                大きさ・線の太さ・位置・色をそろえた 1024×1024 の元画像（12枚）
```

## 画面と機能

| 画面 | 内容 |
|---|---|
| ホーム（記録前） | キャラ＋ふきだし、7日平均・もくひょう・あと、体重入力（タグ・ヘルスケアから読みこみ。体重よそうはオンのときだけ）、もどるまで見守り、もくひょうまで、2週間グラフ、りれき |
| ホーム（記録後） | 体重を大きく表示、7日平均との差、「きょうのきぶん」、**よそうの結果**、**もどるまで見守り**、**ごほうびの日せんげん** |
| グラフ | 1週・1か月・3か月、7日平均線、統計、BMI・体脂肪率、カレンダー（各日に顔と体重） |
| 日の詳細 | カレンダー／りれきで記録のある日を押すと開く日記ページ。前後1週間グラフ、タグ・メモ、前後の日へ移動、「編集」 |
| 記録の入力・修正 | 体重、この日のきぶん、体脂肪率、タグ、メモ。過去日の入力・削除も可 |
| キャラ | おへや（名前をつけられる）、なかよし度、**体重よそうのレベル・成績**、**はらしたもやもや**、ごほうびメダル、ひょうじょうずかん |
| せってい | 身長・目標、判定（7日平均／前日）、きびしめモード、**見ないモード**、通知、**iPhone とのれんけい（ヘルスケア・ウィジェット・ロック画面・Siri）**、ふきだし・ふわふわ動く、各種プレビュー |
| はじめの設定 | 初回起動時の4ステップ（あいさつ → 身長・目標 → 通知 → じゅんび完了） |

## v0.5 で足した機能（差別化）

| 機能 | しくみ |
|---|---|
| 体重よそう（初期はオフ） | せってい › あそび › 体重よそう をオンにした人だけ出る。記録の前に、まえの記録より「ふえた・おなじ・へった」を予想（±0.1kg までは「おなじ」）。キャラも予想する（飲み会・外食・ごほうびの日の翌日は「へった」、ほかは気まぐれ）。当たると 10pt、キャラとちがう予想で当てると +5pt。100pt ごとにレベルアップ。ポイントは減った量では増えない |
| もどるまで見守り | 「飲み会」「外食」タグ、またはごほうびの日（とその翌朝）に、7日平均より 0.1kg を超えて増えた日から見守り開始。体重が「その前の7日平均＋0.1kg」以下にもどったら「はれた！N日でもどった」。2週間もどらなければ、失敗あつかいにせず静かに終了 |
| ごほうびの日せんげん | 記録後のカードで「あしたは ごほうびの日」を宣言。その日と翌朝に増えても、キャラは「ぬくぬく」で「たのしかった？」と受け止め、そのまま見守りに入る。カレンダーに🍰 |
| 見ないモード | 体重の数字をぼかし、グラフの目盛りもかくす。記録後は「きろくしたよ」「いい流れだよ／いつもどおり／ちょっとふえ気味」のことばで伝える |
| シェア（体重カード） | 記録後の「シェア」、日の詳細の「この日をカードにしてシェア」から。1080×1350（4:5）の画像を canvas で作る。「この日」（キャラ・きぶん・セリフ・ながれ・よそうのあたりスタンプ）と「1週間」（7日の顔・目盛りなしの線・記録日数）。体重の数字は「のせる」を選んだときだけ入る（初期はオフ）。いろは4種類。実機では画像ファイルとして iPhone の共有メニューへ |
| iPhone とのれんけい | ヘルスケア同期（読みこみボタンはデモ値）、ホーム画面・ロック画面ウィジェット、ロック画面の記録コントロール、Siri・ショートカットのみため。実際の連携は SwiftUI 版で HealthKit / WidgetKit / App Intents を使って実装 |

### デモで見られるプレビュー（せってい、またはPC表示の右側パネル）
- 通知のみため / ホーム画面ウィジェット / ロック画面ウィジェット / Siri・ショートカット / 3日ぶりに開いたとき / ごほうびのお祝い
- 見ないモードの切りかえ / 体重よそうのオン・オフ / ごほうびの日を宣言してみる / シェアカード
- はじめの設定画面を見る（記録はそのまま）
- 記録0件から体験する（記録を消して初期設定から）

## 表情を差し替える・増やすとき

- 同じファイル名で `assets/characters/` に上書きすれば差し替わります（lg は 720×720、sm は頭と肩まで切り抜いた 240×240）。
- 新しい絵は、いまの12枚と大きさ・線の太さをそろえてから入れてください（頭の幅とほっぺの高さが同じになるように）。
- 「ねぶそく」「さみしい」の絵が届いたら、lg_nightcap / sm_nightcap、lg_lonely / sm_lonely を差し替えるだけで反映されます。
- 表情を増やすときは、`js/app.js` の `MOODS`・`LINES`・`FACE_REPLY` に表情とセリフを追加します。

## デモの範囲

- 通知・ウィジェット・ロック画面・Siri・ヘルスケア・「3日ぶり」は見た目の確認用です（実際の通知や連携はしません）。
- データの保存先は localStorage の `kawaii-weight-v5`（v0.4 までの記録は引きつぎません）。
- 「CSVで書き出す」「きせかえ（準備中）」は見た目だけです。
