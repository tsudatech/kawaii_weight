# かわいい体重管理（デモ v0.4）

キャラクターが体重の変化にリアクションする、iOS アプリの UI デモです。
HTML / CSS / JavaScript だけで動きます。

## 開き方

`index.html` をブラウザ（Safari / Chrome）で開いてください。サーバーは不要です。
データはブラウザの localStorage に保存されます。最初は約3か月分のサンプルデータが入っています。
「せってい › データ › サンプルデータに戻す」で初期状態に戻せます。

## フォルダ構成

```
index.html                 画面の構造
css/style.css              見た目（色・フォントは :root の変数にまとめています）
js/app.js                  動き・表情の判定・サンプルデータ
assets/characters/         キャラ画像
  lg_*.svg                 大サイズ（ホーム・おへや・日の詳細など）
  sm_*.svg                 小サイズ（りれき・カレンダー・きぶん選択など）
  *.png                    追加した表情（440×440、背景透過）
  hidden/                  いまは使っていない表情（workout / congrats）
```

## 画面と機能

| 画面 | 内容 |
|---|---|
| ホーム（記録前） | キャラ＋ふきだし、7日平均・もくひょう・あと、体重入力（タグつき）、もくひょうまで、2週間グラフ、りれき |
| ホーム（記録後） | 体重を大きく表示、7日平均との差、「きょうのきぶん」（自動で決まった顔から全14種類を横スクロールでえらび直せる） |
| グラフ | 1週・1か月・3か月、7日平均線、統計、BMI・体脂肪率、カレンダー（各日に顔と体重） |
| 日の詳細 | カレンダー／りれきで記録のある日を押すと開く日記ページ。前後1週間グラフ、タグ・メモ、前後の日へ移動、「編集」 |
| 記録の入力・修正 | 体重、この日のきぶん、体脂肪率、タグ、メモ。過去日の入力・削除も可 |
| キャラ | おへや（名前をつけられる）、なかよし度、ごほうびメダル、ひょうじょうずかん（全14種類、その顔になった回数） |
| せってい | 身長・目標、判定（7日平均／前日）、きびしめモード、通知、ふきだし・ふわふわ動く、各種プレビュー |
| はじめの設定 | 初回起動時の4ステップ（あいさつ → 身長・目標 → 通知 → じゅんび完了） |

### デモで見られるプレビュー（せってい、またはPC表示の右側パネル）
- 通知のみため / ホーム画面ウィジェット / 3日ぶりに開いたとき / ごほうびのお祝い
- はじめの設定画面を見る（記録はそのまま）
- 記録0件から体験する（記録を消して初期設定から）

## 表情を差し替える・増やすとき

- 同じファイル名で `assets/characters/` に上書きすれば差し替わります。
- PNG の表情を増やすときは、`js/app.js` の `PNG_CHARS` に名前を足し、`MOODS`・`LINES`・`FACE_REPLY` に表情とセリフを追加します。
- `hidden/` の画像を戻すときは、ファイルを `assets/characters/` に移してから同じ手順で追加します。

## デモの範囲

- 通知・ウィジェット・「3日ぶり」は見た目の確認用です（実際の通知は届きません）。
- 「CSVで書き出す」「きせかえ（準備中）」は見た目だけです。
- 画像をファイル参照にしているため、元の SVG を直接埋め込んだ版にあった「涙・キラキラの点滅」はこの版では動きません。SwiftUI 化の際に SVG のグループ（cheek / line / accent / tear / gold）単位でアニメーションを付けられます。
